# ChaiCore — сайт с админкой (PHP + MySQL)

Сайт теперь управляется через админ-панель: все тексты (AZ/RU/EN), фотографии,
логотипы и размеры шрифтов меняются без правки кода.

---

## 📁 Что где лежит

| Файл / папка | Назначение |
|---|---|
| `index.php` | Главная страница сайта (генерируется из базы) |
| `styles.css` | Все стили сайта |
| `config.php` | **Твои данные** — подключение к базе и пароль от админки |
| `functions.php` | Ядро: подключение к БД, авто-установка таблиц, хелперы |
| `content-defaults.php` | Стартовый контент (наполняет базу при первом запуске) |
| `send.php` | Приём заявок из формы → на email |
| `admin/` | Панель управления |
| `assets/` | Исходные фотографии проекта |
| `uploads/` | Сюда сохраняются фото, загруженные через админку |
| `index.html` | Старая статичная версия (можно удалить, не используется) |

## 🚀 Установка на Hostinger (по шагам)

### 1. Создать базу данных
1. Зайди в **hPanel** → раздел **«Базы данных» → «Управление базами данных MySQL»**.
2. Создай новую базу. Hostinger покажет 4 значения:
   - имя базы (напр. `u123456789_chaicore`)
   - имя пользователя (напр. `u123456789_admin`)
   - пароль (тот, что ты задал)
   - хост (обычно `localhost`)

### 2. Заполнить `config.php`
> В GitHub лежит только шаблон **`config.example.php`** (без паролей). Реальный
> файл `config.php` в репозиторий не попадает (он в `.gitignore`) — держи его
> с настоящими данными только у себя и загружай на хостинг напрямую.
> Если поднимаешь с нуля: скопируй `config.example.php` → `config.php`.

Открой `config.php` и впиши значения из шага 1:
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'u123456789_chaicore');
define('DB_USER', 'u123456789_admin');
define('DB_PASS', 'пароль_от_базы');

// придумай СВОЙ логин и пароль для входа в админку:
define('ADMIN_USER', 'admin');
define('ADMIN_PASS', 'смени_этот_пароль');   // ⚠️ обязательно поменяй
```

### 3. Загрузить файлы
Через **File Manager** в hPanel или по **FTP** загрузи всё содержимое папки
`chaicore` в каталог `public_html` (или в папку нужного домена).

Убедись, что загрузились и скрытые файлы: `.htaccess` в корне и в `uploads/`.

### 4. Открыть сайт
Зайди на свой домен — при первом открытии таблицы в базе создадутся
автоматически и наполнятся стартовым контентом. Готово.

### 5. Войти в админку
Открой `https://твойдомен/admin/` → введи `ADMIN_USER` / `ADMIN_PASS` из `config.php`.

## 🛠 Что можно менять в админке

- **Тексты** — все надписи сайта на трёх языках (AZ / RU / EN).
- **Фото** — заменить любое изображение и логотип, удалить, а в галерею
  добавлять/удалять сколько угодно фотографий.
- **Настройки:**
  - **Размеры шрифтов** — общий масштаб всего текста + отдельно заголовок hero,
    заголовки секций и доп. масштаб для телефонов (в процентах).
  - **Контакты** — телефон, email, Instagram, адрес.
  - **Google Maps** — вставь код `<iframe>` карты (Google Maps → «Поделиться» →
    «Встроить карту» → скопировать HTML).
  - **Соцсети** — ссылки на все соцсети.
  - **Цифры** «О нас» (500+, 20+ и т.д.).

Изменения появляются на сайте сразу после нажатия «Сохранить».

## ✉️ Заявки с формы
Заявки уходят на email из настройки **«Email для заявок»**
(Настройки → Форма заявки). На Hostinger функция почты работает по умолчанию.

---

## 🔐 Безопасность
- Обязательно смени `ADMIN_PASS` в `config.php` перед публикацией.
- Папка `uploads/` защищена от запуска скриптов (`.htaccess`).
- Загружать можно только изображения (JPG, PNG, GIF, WEBP).
- Файлы `config.php` / `functions.php` закрыты от прямого доступа из браузера.

---

## 💾 Резервная копия
- **Контент** хранится в базе MySQL → делай экспорт базы в hPanel → phpMyAdmin.
- **Фото** лежат в папках `assets/` и `uploads/` → сохраняй их копию.

---

## ↩️ Сброс к стартовому контенту (если нужно)
В phpMyAdmin выполни: `DELETE FROM cc_settings WHERE skey='_installed';`
и удали строки из таблиц `cc_texts`, `cc_settings`, `cc_images` — при следующем
открытии сайта они заполнятся заново из `content-defaults.php`.
